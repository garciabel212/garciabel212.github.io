# Jose Garcia — Professional Portfolio V2

Personal portfolio and technical case study hub for **Jose Garcia**, Computer Engineer specializing in **Solutions Engineering**, **Sales Engineering**, and **Technical Consulting**.

🌐 **Live Website**: [garciabel212.github.io/About-Me](https://garciabel212.github.io/About-Me/)

---

## 🛠️ Architecture & Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS + Custom Design System tokens (editorial clamp typography, glassmorphism, luminous radial gradients)
- **Animation**: Framer Motion + RAF lerp magnetic buttons + mouse parallax
- **Routing**: React Router DOM (HashRouter for seamless GitHub Pages compatibility)
- **Deployment**: GitHub Actions workflow (`.github/workflows/deploy.yml`) targeting GitHub Pages

---

## 🚀 Key Case Studies

1. **Service Map Planner**: Field-service operations platform designed and built for biomedical hardware technicians to map 150+ customer institutions across multi-state territories, track warranties, and optimize travel logistics.
2. **Scale Garage Studio**: Browser-based interactive 3D configurator engineered in WebGL / Three.js for scale-model collectors and diorama builders, featuring real-time parametric geometry and direct STL export for 3D printing.
3. **Enterprise Multi-Site Hardware & OS Rollout**: Deployment and standardization of 150+ specialized book and document scanning workstations across major academic, government, and healthcare institutions.
